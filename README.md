# Car Showroom

Showroom 3D interativo em WebGL — React, TypeScript, Tailwind CSS v4 e React Three Fiber.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build
```

- Pintura e rodas com transição suave de material, 6 ângulos de câmera, giro automático
- Iluminação Noite / Estúdio (`?mode=studio` abre direto no modo claro)
- CTA fixo depois do primeiro scroll, ficha técnica e formulário de test drive
- Modelo 3D: "Ferrari 458 Italia" por vicent091036 (CC BY 3.0), via exemplos do three.js. Showroom de Julia Nascimento.
